# 💬 Discord Clone

Clone da interface do site do **Discord**, desenvolvido com **HTML5** e **CSS3**, com foco em praticar estruturação de layouts, estilização e responsividade.

Este projeto foi criado como parte do meu aprendizado em desenvolvimento web front-end.

---

## 🖥️ Preview

🔗 **Acesse o site publicado:**  
👉 https://clone-discord-chi.vercel.app/

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Layout responsivo
- Sem frameworks ou bibliotecas externas

---

## 🎯 Objetivos do projeto

- Praticar **HTML semântico**
- Treinar **CSS moderno**
- Reproduzir layouts reais usados no mercado
- Melhorar organização de código e estrutura de pastas

---

## 📱 Responsividade

O layout foi desenvolvido para se adaptar a diferentes tamanhos de tela, incluindo:
- Desktop
- Tablets
- Smartphones
